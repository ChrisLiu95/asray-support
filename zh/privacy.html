隐私政策

本政策说明 A.S.Ray Intelligence（睿卿）App 及本支持网站如何处理信息。您无需登录即可阅读本政策。

01我们处理的信息

账号、密码和邀请码用于注册和登录。密码以加盐哈希形式存储在服务端，App 将登录令牌保存在系统安全存储中。您发送的咨询文字、语言、服务偏好及会话记录用于提供 AI 礼宾回复和恢复历史。不要在咨询中发送无关的证件、金融、健康信息或他人的敏感信息。

02图片、位置和语音

您主动选择或拍摄并发送的图片用于识别；上传前会重新编码、缩放并移除元数据，但画面中的个人信息仍然可见。当前图片识别在服务后端处理，不通过 DeepSeek 识别图片。附近地点查询仅在您提出请求并授予定位权限时发送当次坐标，不持续后台定位。语音通过系统语音服务转换为未发送的文字草稿，您点击发送后才提交文字；App 不保存录音或将录音上传给本服务，系统语音服务可能联网处理。

03申请资料和本机副本

邀请和服务申请包含姓名、公司、职务、邮箱、电话、申请项目、语言及状态，并与账号关联。我们使用这些信息处理申请和联系您；提交申请本身不构成同意营销。资料可能由必要的服务处理人员访问；如需向实际供应商提供资料，应另行向您说明。App 保存语言、币种等偏好；当前客户端不把聊天正文作为普通本机偏好持久化。保存至系统相册的邀请函副本由您管理。

04AI 和服务提供方

AI 文字答复使用 DeepSeek 官方 API。为生成相关答复，后端可能发送您本次咨询文字、会话状态、检索到的服务信息及上下文；因此请勿输入不必要的个人信息。第三方处理按实际服务条款及其政策执行，我们不承诺第三方零保留或不用于训练。请参阅 DeepSeek 隐私政策。服务后端托管于 Microsoft Azure，相关信息参见 Microsoft 隐私声明。处理地点可能与您所在地不同；您可联系我们了解数据接收方和跨境处理情况。

05授权与选择

您可在系统设置中管理相机、相册、麦克风、语音和定位权限。新增授权功能的 App 版本会在首次发送 AI 咨询前说明 DeepSeek 及共享信息，只有点击“同意并继续”才发送。拒绝后仍可浏览分类、资料及提交邀请申请。授权仅在当前登录会话内有效；退出或重启后重新询问。可在侧边栏“AI 数据授权”中撤回，阻止后续 AI 请求并取消仍在等待的请求；已发送的数据无法收回，按本政策处理。未提供该界面的旧版本请先更新，再使用 AI 咨询。隐藏对话只改变本机列表，不删除服务器记录。

06保存、删除和安全

账号、聊天记录和申请资料在您使用服务期间保留，目前没有按固定天数自动删除的统一机制。您可以申请删除账号及相关资料。在支持注销的新版 App 中，打开账号抽屉 → 注销账号，输入当前密码并确认；只有服务器确认成功才代表在线账号数据已删除。若您的版本没有入口或服务暂不可用，请通过下方邮箱提交删除请求，由我们核验和处理，并告知处理情况。退出登录和卸载不等于注销。

07删除范围和保留例外

账号注销覆盖在线账号、登录会话、聊天、邀请申请和日程；不会自动删除您保存到相册的副本。备份、运维或安全日志，以及依法必须保留的信息可能不与在线数据同时删除。我们将对相关请求说明适用范围、保留理由和处理安排；第三方已经处理的数据还受其实际条款约束。HTTPS 和安全存储用于降低泄露风险，但不构成端到端加密或绝对安全保证。

08您的权利、未成年人和更新

如需访问、更正、复制、删除信息、撤回许可或提出隐私投诉，请联系本页邮箱。我们可能请求处理该事项所必需的身份核验信息；不要发送密码或登录令牌。服务不面向儿童；未成年人应在监护人指导下使用，不得自行进行不具备相应能力的交易。如发现儿童信息，请联系我们处理。政策变更将发布在本页；需要另行告知或取得许可的事项将另行处理。

09本网站

这些网页托管于 GitHub Pages，不要求登录，不包含我们部署的广告、分析脚本或表单追踪。GitHub 会为安全目的记录访问者 IP 地址，参见 GitHub Pages 说明。点击邮箱链接会打开您的邮件服务，邮件处理适用该服务的规则。
